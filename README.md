# Programming Problems — Java Learning Path

Solutions are grouped by problem-solving technique. Start with **arrays → hashing → two pointers → sliding window → binary search → stack → sorting → intervals → backtracking → bit manipulation → strings → math → design**. This is a suggested path, not a prerequisite rule.
